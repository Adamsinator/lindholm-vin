        Export your cellar

        Download a copy of your cellar to keep or to work on in Excel, Numbers or Google Sheets. It uses the same columns as the import, so the file imports straight back.

        Share a list of your wines

        Anyone with the link can see the list, read-only, until it expires or you withdraw it. It's encrypted in this browser: the key is only in the link, so AllWine can't read it.

        Your shared lists

          Import wines

          Add many wines at once from an Excel workbook (.xlsx), a CSV file or a text file — one wine per row. Column headings in Danish, English, French or German are recognised, and you can correct the matching before anything is saved.

          No file?

          One wine per row; only the producer is needed. Tab and Enter move between the cells, and rows copied from Excel or Numbers can be pasted straight in. Then check them, and add them all at once.
